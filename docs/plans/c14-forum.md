# C14 포럼형 게시판 — 계획 (단위 11e)

> GAP C14. 최근 활동순 목록, 답변(댓글) 채택, 글 잠금. 커뮤니티 테마(퀘이사존 분석 뒤)의 질문·토론 게시판이 이 셋에 기댄다.

## 1. 결정 (추천안 채택)

| # | 결정 | 추천안(채택) | 대안 |
|---|---|---|---|
| D1 | 종류 | 게시판 종류에 `forum` 을 더한다. 목록 순서는 게시판 칸 `list_order`(`""`·`latest`·`activity`)로 따로 고를 수 있고, 빈 값이면 `forum` 만 `activity` | 종류에 묶기만 — 자유게시판을 활동순으로 못 바꾼다 |
| D2 | 활동 시각 | `posts.last_activity_at`(없으면 발행 시각). 공개된 댓글이 달릴 때(바로 공개·승인), 공개된 답변글이 달릴 때 맨 위 글 값을 올린다. 숨김·삭제로 되돌리지 않는다 | 읽을 때마다 댓글 최댓값 계산 — 목록 쿼리가 무거워진다 |
| D3 | 채택 | `posts.accepted_comment_id`. `qna`·`forum` 게시판에서만. 글쓴 회원 본인 또는 그 게시판 관리자(`PostModerate`)가 고르고 바꾸고 뺀다. 공개된 이 글의 댓글만. 채택한 댓글이 공개 상태가 아니면 화면에는 없는 것으로 본다 | 답변글(C9) 채택 — 퀘이사존·지식인류는 댓글 채택이 흔하다 |
| D4 | 잠금 | `posts.is_locked`. 관리자만 잠그고 푼다. 잠긴 글에는 새 댓글·답변글·고치기·지우기(글과 댓글 모두)가 관리자 말고는 안 된다(`error.post_locked`). 읽기는 그대로 | 댓글만 막기 — 분쟁 글 정리에 모자란다 |
| D5 | 표시 | 목록: 잠금 표시, 채택된 글은 「해결」 표시, 활동순이면 마지막 활동 시각. 글 화면: 잠금 안내(댓글 폼 대신), 채택 댓글은 댓글 목록 위에 「채택된 답변」으로 한 번 더, 댓글마다 「채택」 단추(고를 수 있는 사람에게만) | |

## 2. 다섯 경로

- **데이터**: 마이그레이션 `forum`(boards.list_order, posts.last_activity_at·accepted_comment_id·is_locked, 활동순 색인). down 은 열·색인 지우기.
- **core**: `Board::effective_order`, `posts::lock`, `posts::accept`, 댓글·답변·고치기·지우기의 잠금 검사, 활동 시각 올리기.
- **REST**: `POST /posts/{id}/lock {locked}`, `POST /posts/{id}/accept {comment_id|null}`, 게시판 JSON `list_order`.
- **CLI**: `post lock <id> [--off]`, `post accept <id> --comment <cid> | --clear`, `board create|update --order`.
- **화면**: 공개 목록·글 화면, 관리 편집기 잠금 칸.
- **MCP**: Phase 3.

## 3. 작업 단위

| 단위 | 내용 | 테스트 |
|---|---|---|
| T1 | 마이그레이션·모델·storage(활동순 정렬) | 올리고 내리기 |
| T2 | 서비스(잠금·채택·활동 시각) | 저장소: 활동순 순서, 채택 권한·대상 검사, 잠금 거부·관리자 허용, 감사 |
| T3 | REST·CLI·화면 | e2e: CLI 잠금·채택 → DB, 공개 화면 표시, 잠긴 글 댓글 거부, 글쓴이 채택 단추 → DB |
| T4 | 브라우저, ADR-0058, GAP | 게이트 |

완료 기준: `forum` 게시판에서 오래된 글에 댓글이 달리면 목록 맨 위로 오고, 글쓴이가 댓글을 채택하면 DB 와 화면에 남으며, 잠근 글에는 회원 댓글이 거부된다.

## 4. 진행

- [x] T1~T4 — ADR-0058.
- 계획과 달라진 점: 잠금은 글 되돌리기(리비전)·채택도 막는다. 승인·되살리기로 공개되는 댓글도 활동으로 친다. 「채택」 단추는 손님 기준 화면이라 모두에게 보이고, 권한은 확인 화면에서 본다.
