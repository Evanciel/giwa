# 네이버 블로그·티스토리 글쓰기 화면 비교 (2026-11-03)

> ego-browser 로 로그인된 실제 글쓰기 화면을 **보기만** 하고 정리했다(입력·저장·발행 없음).
> 원칙 7(ADR-0040): 배치·사용 흐름은 참고, 코드·아이콘·이미지·문구는 가져오지 않는다.
> 비교 대상은 우리 에디터 2737066(글쓰기 화면 개편) 기준.

## 4. 우리에게 필요한 것 (제안 순서)

1. **카테고리 · 태그 · 공지 · 비공개** — 두 곳 모두 있고 GAP_PLAN 단위 6 과 그대로 겹친다. 발행 서랍에 넣는다.
2. **댓글 허용 · 검색 허용(noindex) · 이 설정을 기본값으로** — 발행 서랍 토글 셋. 댓글 기능(GAP_PLAN)과 같이.
3. **밑줄 · 양쪽 정렬** — 작은 일. 밑줄은 Markdown 에 문법이 없어 `<u>` 를 ammonia 허용 목록에 넣을지 결정 필요.
4. **임시 저장 글 목록** — 위 막대에 개수 + 눌러서 고르기. 지금은 마지막 저장 시각만 보인다.
5. **빈 줄 「+」 넣기 단추** — 넣기 도구를 커서 자리에서 바로. 휴대폰 폭에서 특히 쓸모.
6. **휴대폰 화면 미리보기** — 미리보기를 PC/휴대폰 폭으로 바꿔 보기.
7. **라이브러리** — 올렸던 사진을 본문에 다시 넣기(미디어 목록 API 재사용).
8. **부분 틀** — 글 틀을 커서 자리에 끼워 넣기(지금은 전체 교체).
9. **문단 종류 한 단계 더(제목3)**, **단축키 도움말**, **수식**(기술 블로그용, 새 의존성 필요) — 나중.

하지 않을 것: 임의 서체·줄간격 직접 지정(테마 토큰과 충돌. 서체는 정해진 넷만, ADR-0047), HTML 블럭·HTML 모드(정화 원칙과 충돌, 필요하면 관리자 전용 별도 결정), 번역·플랫폼 전용 기능(일정·내돈내산·광고).

## 5. 확인 중 생긴 일

- 티스토리 글쓰기를 열 때 「09:58 에 저장된 글을 이어서 쓸까요?」 창이 떠서, 임시 글이 지워지지 않도록 「확인」을 눌렀다. 불러온 글은 제목·본문이 비어 있었고, 그 뒤 티스토리가 스스로 자동 저장했다(14:19). 우리가 입력한 것은 없다.

## 6. 글자 꾸밈 메뉴 자세히 (2026-11-03 추가)

같은 방식(보기만, 메뉴를 열어 보기만 하고 본문에 적용하지 않음)으로 다시 봤다.

| 항목 | 네이버 | 티스토리 | Maru (ADR-0046) |
|---|---|---|---|
| 글자 크기 | 툴바에 숫자 드롭다운. 11·13·15(기본)·16·19·24·28·30·34·38, 지금 값에 체크 | 크기 단추 없음. 문단모양(제목1~3·본문1~3)을 항목마다 실제 크기로 미리 보여 줌 | 「본문」+ 11~38 열 단계, 숫자는 실제 크기에 가깝게(24 까지) 보임 |
| 툴바에 지금 값 | 크기 숫자 | 글자색 아이콘의 점이 지금 색 | 크기 숫자, 글자색·형광펜 아이콘 아래 색 막대 |
| 글자색 | 12열×6행 격자(무채색 + 10색상 × 명도). 첫 칸 「색상 없음」. 「더보기」로 색상판·hex 입력 | 둥근 견본 7×5(34색). 첫 칸 「없음」, 지금 색에 체크, 아래 hex 입력 | 「기본」+ 12색, 견본은 그 색 「가」 |
| 배경색 | 글자색과 같은 72칸 | 글자색과 같은 34색 | 「없음」+ 형광펜 8색(반투명) |
| 임의 색 | 색상판 + hex | hex 입력 | 없음(테마·어두운 화면 대비) |
| 고른 뒤 | (본문에 적용해 보지 않아 확인 안 함) | (같음) | 서식 모드는 남는다, Markdown 모드는 닫힌다 |

배운 것: ① 「없음」은 맨 앞에 둔다(두 곳 모두). ② 지금 값을 툴바와 메뉴 둘 다에서 보인다. ③ 크기는 이름(작게·크게)보다 숫자가 익숙하다. ④ 미리보기는 실제 모양으로(티스토리 문단모양).

하지 않은 것: 72칸 격자·임의 색(대비·사이트 통일), 최근 쓴 색(두 곳 모두 없음), 임의 서체(정해진 넷은 ADR-0047 에서 넣음).

- 확인 중: 티스토리 글쓰기를 다시 열 때 「14:19 에 저장된 글을 이어서 작성하시겠습니까?」가 떠서 지난번처럼 임시 글이 지워지지 않게 「확인」을 눌렀다. 그 뒤 티스토리가 스스로 자동 저장했다(16:12). 우리가 입력한 것은 없다.
