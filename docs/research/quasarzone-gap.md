# 퀘이사존 기능 ↔ Maru 비교표 (2026-11-05)

> 근거: `docs/research/quasarzone.md`의 관찰, Maru `docs/GAP_PLAN.md`·`docs/DECISIONS.md`(ADR-0054·0058·0059·0067·0068·0070·0081·0082·0084), 저장소 템플릿·마이그레이션 읽기 전용 확인.
> 상태: 있음 / 부분 / 없음. 「?」는 코드에서 확인하지 못한 것.
> 원칙 7: 기능을 맞추는 것이지 모양을 옮기는 것이 아니다. 화면은 Maru 토큰·위젯으로 새로 만든다.

## 1. 비교표

## 2. 만들 가치가 큰 빠진 기능 (우선순위)

1. **이름 옆 레벨 표시(아이콘·이름)** — 모듈. 포인트 모듈이 `post_list` 처럼 이름 묶음을 받아 `{회원: 레벨}` 을 내는 화면 자리(`member_badge`)를 만들고 테마가 이름 앞에 그린다. 레벨 기준 설정을 `{min, name, icon}` 로 넓힌다. 코어 회원 표는 그대로.
2. **공개 회원 프로필 화면 + 작성자 카드** — 코어(회원 도메인)에 공개 프로필 조회 서비스(닉네임·가입일·자기소개·최근 공개 글/댓글, 비밀글 제외)와 `/u/{닉네임}`. 쪽지·차단·레벨·포인트는 모듈 자리(`profile_sections`)로 붙인다. 글 보기 아래 카드는 같은 서비스를 쓴다.
3. **탭 묶음 위젯** — 코어 위젯 종류 하나 추가(`tabs`: 자식 위젯 ID 목록). 첫 화면 「콘텐츠」「베스트」「핫딜」 판을 탭으로 묶는다. 탭 전환은 스크립트 없이 `<details>`/라디오 또는 작은 JS, 자동 회전은 넣지 않는다(접근성).
4. **핫딜 모듈** — 모듈(`mods/deal`). 여분 필드(판매처·가격·배송비·링크)를 쓰는 게시판 프리셋 + 「종료」 상태(글쓴이·운영자 처리, 신고 누적 자동 종료) + 목록 줄 표시(`post_list` 자리) + 종료 제외·판매처 거르기. 코어에는 「여분 필드 거르기」(C10 Phase 2(b))만 일반 기능으로 둔다.
5. **인기 표시와 인기글 거르기** — 반응 모듈이 게시판별 기준(추천 N 이상 또는 조회 N 이상)을 설정으로 받아 `post_list` 자리에 `hot: true` 를 내고, 「인기글」 탭은 모듈이 글 ID 목록을 주는 거르기 확장 지점으로.
6. **전 게시판 모아보기(인기글·전체 새 글)** — 코어 화면. 손님이 읽을 수 있는 게시판의 새 글을 한 목록으로(`/recent`), 인기는 반응 모듈 협조(`/best`). 피드·사이트맵의 「공개 글」 쿼리를 재사용.
7. **목록 정렬(추천·조회) + 검색 범위(댓글·닉네임)** — 코어. 조회 순·댓글 순은 코어 쿼리, 추천 순은 반응 모듈이 정렬 키를 주는 방식. 검색은 FTS 에 댓글 색인·닉네임 조건 추가.
8. **댓글 개선 묶음(정렬·글쓴이 표시·댓글 추천 표시·이미지)** — 코어 댓글 서비스에 정렬과 글쓴이 판정, 반응 모듈 `comment_footer` 자리, 댓글 이미지는 미디어 서비스 재사용(회원만, 개수 제한).
9. **게시판 안내 문구 + 게시판 베스트 카드** — 코어 `boards.description` 열(마이그레이션 + 롤백), 게시판 머리에 표시. 베스트 3 카드는 `popular_posts` 위젯의 `style: cards` 설정.
10. **출석체크** — 포인트 모듈 확장. 하루 1회 출석 기록(`source = attend:<회원>:<날짜>` 로 멱등), 연속 일수·달력 화면 `/m/point/attendance`, 회원 막대 항목.

넣지 않기를 권하는 것: 배너 클릭 포인트(부정 클릭 유도), 화면 양옆 스킨 광고, 자동 회전 판(읽는 중에 바뀜), 데스크톱 고정 폭 1200px(Maru 는 반응형 유지).
