# 단위 11c — 답변글(계층) (GAP C9)

> 2026-11-04. 결정 표는 추천안으로 진행(사용자 지시). 질문·문의 게시판(qna)에서 관리자·회원이 글 아래에 「답변」 글을 단다. 댓글과 달리 제목·본문·리비전이 있는 글이다.

## 1. 결정

| # | 결정 | 추천안(채택) | 대안 |
|---|---|---|---|
| D1 | 저장 | `posts.parent_id`(바로 위 글, FK), `posts.thread_id`(맨 위 글 id, 맨 위 글은 비움), `posts.thread_path`(형제 순서 `0001.0002.` — 깊이마다 4자리). 깊이 최대 5 | 정렬 문자열 하나(그누보드 `wr_reply`) — SPEC 이 버린 방식. 중첩 집합 — 쓰기가 비싸다 |
| D2 | 목록 정렬 | 스레드끼리는 맨 위 글 발행순, 스레드 안에서는 `thread_path` 순. 답변은 목록 번호를 받지 않고 들여쓰기 + 「답변」 표시 | 답변을 목록에서 빼고 글 화면에만 — 한국형 게시판 사용 흐름과 다르다 |
| D3 | 누가 다나 | 게시판 정책 `reply`(최소 역할, `none` 이면 받지 않음). 기본: qna → `editor`, 나머지 → `none` | 쓰기 권한과 같게 — 공지·갤러리에 답변이 열린다 |
| D4 | 서비스 | `posts::reply(parent, ReplyInput)` — 관리 경로(초안 → 발행, 에이전트도 됨). 공개 화면은 `board_posts::write` 에 `reply_to`(회원·손님, 정책 `reply`·`write` 둘 다). 분류는 위 글을 따르고, 위 글이 비밀글이면 답변도 비밀글 | `NewPost` 에 `parent` 칸 — 기존 리터럴 24곳이 바뀐다 |
| D5 | 비밀 답변 | 비밀 답변은 쓴 사람·관리자에 더해 **맨 위 글을 쓴 사람**도 읽는다(문의 게시판의 기본 흐름) | 답변 쓴 사람만 — 질문한 사람이 답을 못 본다 |
| D6 | 지우기 | 답변이 달린 글을 지워도 답변은 남는다(상태 `deleted` 는 목록에서 빠지고 답변은 「원글이 지워진 답변」 으로) | 함께 지우기 — 답변 쓴 사람의 글이 사라진다 |

## 2. 다섯 경로

- **데이터**: 마이그레이션 `posts_thread`(세 열 + 인덱스 `posts(thread_id)`, down: 인덱스·열 지우기).
- **core**: `Post.parent_id`·`thread_id`·`thread_path`·`depth()`, `BoardPolicy.reply`, `posts::reply`, `board_posts::write` 의 `reply_to`, 비밀글 규칙.
- **REST**: `POST /posts/{id}/reply`.
- **CLI**: `maru post reply <id> --title --body [--publish]`, `board update --reply <역할|none>`.
- **공개 화면**: 목록 들여쓰기·답변 표시, 글 화면 「답변 쓰기」(정책이 열려 있을 때), `/write/{board}?reply=<글 슬러그>`.
- **관리 화면**: 편집기 「답변 쓰기」 → 새 글 화면이 위 글을 기억(`/admin/posts/new?reply=<id>`).
- **MCP**: Phase 3.

## 3. 작업 단위

| 단위 | 내용 | 테스트 |
|---|---|---|
| T1 | 마이그레이션·storage·모델·정렬 | 올리고 내리기, 목록 정렬 |
| T2 | `posts::reply`, 정책, 깊이, 비밀 답변 | 저장소: 답변 경로·깊이 제한·정책 none 거부·비밀 상속·질문자가 비밀 답변 읽기·남은 답변 |
| T3 | REST·CLI | e2e 안에서 |
| T4 | 공개 화면·관리 화면 | e2e: CLI 답변 → 목록 순서(원글 바로 아래)·들여쓰기, 회원이 공개 화면에서 답변 → DB `parent_id` |
| T5 | 브라우저, ADR-0056, GAP | 게이트 |

완료 기준: qna 게시판 글에 관리자가 답변을 발행하면 목록에서 원글 바로 아래 들여써 보이고, DB 의 답변 행 `parent_id`·`thread_id` 가 원글 id 다.

## 4. 진행

- [x] T1~T5 — ADR-0056.
- 계획과 달라진 점: 비밀 답변을 동기 함수로 판단하려고 `thread_owner`(맨 위 글을 쓴 회원) 칸을 하나 더 두었다. 답변도 목록 번호를 받는다(번호는 화면 위치라 빼면 번호가 건너뛰어 보인다). 공개 답변 주소는 글 슬러그 대신 글 id(`?reply=<id>`). 관리 화면은 새 글 화면 대신 편집기 안 작은 폼으로 답변 초안을 만들고 그 편집 화면으로 간다.
