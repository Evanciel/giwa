## 1. Wix 에 있고 Maru 에 없는 것

| Wix 에서 하는 일 | 지금 | 단위 |
|---|---|---|
| 섹션 고르기(동영상·사진 모음·로고 줄·카운트다운·SNS·인용) | 섹션 14종. 동영상·로고·카운트다운·SNS 섹션 없음 | W1 |
| 원페이지: 메뉴를 누르면 같은 화면의 구역으로 이동(앵커) | 없음 | W1 |
| 섹션 배경 그림, 등장 효과 | 띠 색 3가지만. 등장 효과는 E 단계에서 일부러 뺐음 | W2 |
| 템플릿을 보고 골라 시작·바꾸기 | 설치 때 프리셋, 빈 화면 시작 묶음 3장 | W3 |
| 섹션 저장해 다시 쓰기, 다른 페이지로 복사 | 같은 화면 안 복제만 | W4 |
| 페이지 SEO·공유 그림을 편집기에서 | `/admin/pages` 따로 | W5 |
| 사이트 기록에서 되돌리기 | 방금 발행한 묶음만 되돌리기 단추 | W5 |
| 동영상 올리기 | 유튜브·비메오 주소만 | W6 |
| 휴대폰 앱처럼 쓰기 | 없음 | W7 |

**Wix 보다 앞서는 것**(지금도, 그리고 이 계획에서 지킬 것): 발행 한 번 = 묶음 하나 = 한 번에 되돌리기, 에이전트가 같은 서비스로
같은 일을 한다(REST·CLI·MCP), 단일 바이너리·내 컴퓨터, 외부 추적 없음, 색은 토큰 안에서만이라 대비가 깨지지 않는다,
등장 효과는 「움직임 줄이기」 설정을 따른다.

## 2. 작업 단위 (순서대로. 단위마다 ADR·게이트 커밋·브라우저 확인·미니PC 배포)

### W1 새 섹션 6종 + 원페이지 앵커 (ADR-0156)

- 섹션 종류 더하기(`core::services::sections`, 두 스킨 템플릿·CSS, 편집기 카드):
  - `video` 동영상: 유튜브·비메오 주소(ADR-0036 의 검증 그대로), 제목·설명, 가로세로 비율. W6 뒤 올린 동영상도.
  - `gallery` 사진 모음: 그림 2~24장, 격자·가로 넘김 모양, 캡션, 누르면 크게(스크립트 없이 `:target` 또는 `<dialog>`).
  - `logos` 함께하는 곳: 그림 + 이름 + 링크 2~24개, 흑백으로 가라앉히기 선택.
  - `countdown` 남은 날: 목표 날짜·시각, 지나면 보일 문구. 서버가 D-day 를 그리고 스크립트가 있으면 시·분을 갱신.
  - `social` SNS 단추: 인스타그램·유튜브·블로그·카카오톡 채널·X·페이스북·스레드·틱톡·이메일·전화. 상표 로고 그림은 쓰지 않고
    글자 단추(원칙 7). 주소 형식은 서버가 검사(https·mailto·tel).
  - `quote` 큰 인용: 한두 문장 + 누가 했는지.
- 앵커: 섹션 공통 칸 `anchor`(영문 소문자·숫자·`-`, 32자) → `<section id="s-…">`. 링크 고르기 판에 「이 화면의 구역」.
  메뉴 링크로 `/#s-menu` 처럼 쓴다. `scroll-margin-top`, 부드러운 이동은 `prefers-reduced-motion` 이면 끔.
- 서비스가 같은지: 위젯 설정 검증 한 곳이라 REST·CLI(`widget add --kind video`)·MCP 가 자동으로 같다.
- 테스트: 단위(각 종류 기본값·잘못된 값 거절·앵커 형식·겹치는 앵커), e2e(공개 HTML 에 `id="s-…"`·동영상 iframe 주소 검증·SNS
  주소 거절), 브라우저(편집기에서 넣고 고치고 발행).

### W2 섹션 배경 그림·등장 효과 (ADR-0157)

- 공통 칸 `bg_image`(보관소 그림)와 `bg_dim`(`light`·`medium`·`strong`, 기본 medium). 배경 그림이 있으면 어두운 덮개 + 밝은 글자로
  대비를 보장한다(토큰 밖 색을 고르게 하지 않는다). 꾸미기 탭에 그림 고르기(E1 그림 판 재사용).
- 공통 칸 `motion`(`none`·`fade`·`rise`, 기본 none). CSS 와 IntersectionObserver 몇 줄. 스크립트가 없으면 그냥 보이고,
  움직임 줄이기면 움직이지 않는다. 편집 캔버스에서는 끈다(고르기·끌기 방해).
- ADR 에 `editor-wix-gap.md` §1 「애니메이션 편집 안 함」을 바꾸는 까닭: 키프레임 편집이 아니라 정해진 세 가지만, 접근성 설정 존중.

### W3 디자인 모음 — 보고 골라 바꾸기 (ADR-0158)

- 편집기 네 번째 판 「디자인 모음」: 프리셋 22종의 첫 화면 + 새 원페이지 디자인(소개·행사·포트폴리오)을 카드로(이름·설명·색 견본).
- 고르면 **초안으로만** 바뀐다: 이 화면의 본문 블록을 그 디자인의 블록으로, 사이트 토큰은 그 디자인의 색·모서리로. 캔버스에서
  보고 마음에 안 들면 「원래대로」. 발행하면 한 묶음, 묶음 되돌리기 한 번으로 원래대로.
- 단추·링크는 ADR-0155 의 `fit_links` 로 이 사이트의 게시판·페이지에 맞춘다. 바꾸기 전에 「블록 N개를 바꿉니다」 확인.
- 서비스: `core::services::designs::{list, get}`(프리셋 TOML 의 `widgets.ensure`·`tokens.ensure` 를 읽음) → REST
  `GET /api/v1/designs[/{id}]` → CLI `maru design list|show` → MCP `list_designs`. 적용은 지금의 발행 묶음(changeset) 그대로.

### W4 내 블록 저장·다른 화면으로 복사 (ADR-0159, 마이그레이션 있음)

- 새 표 `saved_blocks(id, name, kind, title, config, created_by, created_at)` + down. 서비스 `saved_blocks::{list, save, delete}`
  (디자인 권한) → REST → CLI `maru block saved …` → MCP.
- 층 판·블록 메뉴 「내 블록으로 저장」, 더하기 판 「내 블록」 묶음. 복사·붙여넣기(Ctrl+C·Ctrl+V)는 다른 화면에서도 된다
  (브라우저 저장, 붙이면 새 블록 id).

### W5 편집기 안 페이지 설정·사이트 기록 (ADR-0160)

- 「페이지 설정」: 제목·주소·검색 설명·공유 그림·검색에서 빼기. 발행 묶음에 같은 페이지 서비스 연산으로 들어간다.
  검색 결과·공유 카드 미리보기(글자 수 경고).
- 「사이트 기록」: 최근 묶음 목록(언제·누가·무엇 몇 개, 사람/에이전트 구분). 눌러 그 묶음만 되돌리기(지금 서비스 그대로).

### W6 동영상 파일·코드 복사 (ADR-0161)

- mp4·webm 올리기(서명 검사, 한도 설정 기본 200MB), 공개 응답 `Range`·`206`, `preload="metadata"`.
- 글 `::video[/media/…]{loop muted autoplay}`(자동 재생이면 음소거 강제), `video` 섹션에서 올린 동영상 고르기.
- 공개 글 코드 블록에 「복사」 단추(스크립트 있을 때만 보임).

### W7 홈 화면에 추가 (ADR-0162)

- `/manifest.webmanifest`(사이트 이름·토큰 색·아이콘). 아이콘은 사이트 로고, 없으면 이름 첫 글자로 서버가 PNG 를 그린다.
- 서비스 워커는 오프라인 안내 한 쪽만 캐시(로그인·관리 화면·개인 응답은 캐시하지 않음). 설정 `site.pwa`(기본 켬)로 끈다.

### W8 마무리 점검

처음 쓰는 사람 과제를 브라우저로 그대로 한다: 디자인 모음에서 원페이지 고르기 → 배경 그림·등장 효과 → 앵커 메뉴 →
동영상·사진 모음·SNS 섹션 → 내 블록 저장해 다른 페이지에 → 페이지 설정 → 발행 → 사이트 기록에서 되돌리기 → 휴대폰에서 홈 화면에 추가.
막힌 곳을 고치고 결과를 이 문서 끝에 표로 남긴다. 주 색을 고를 때 대비 4.5 미만이면 경고하는지도 본다.

## 5. W8 점검 결과 (2026-11-12, ADR-0163)

로컬 데모(식당 유형으로 만든 새 사이트)에서 처음 쓰는 사람 과제를 브라우저로 그대로 했다.

| 단계 | 결과 | 막힌 곳과 고친 것 |
|---|---|---|
| 디자인 모음에서 고르기 | 됨 | 없음 |
| 배경 그림·등장 효과 | 됨 | 없음 |
| 주 색 고르기(대비 경고) | 됨, 고침 | 경고가 판 맨 아래에 토큰 이름(`color.primary / color.bg`)으로 떠 못 알아봤다. 색 바로 아래에 「주 색이 바탕과 너무 비슷해 단추·링크가 잘 안 보입니다(대비 1.07:1, 4.5:1 이상 필요)」로 보인다. |
| 구역 이름 붙이고 메뉴에서 그 구역으로 | 됨, 고침 | 메뉴의 갈 곳 고르기에 구역이 없어 `/#s-…` 를 손으로 써야 했다. 「이 화면의 구역」 묶음을 더했다. 손으로 쓴 같은 주소도 그 구역으로 보인다. |
| SNS 섹션에 링크 더하기 | 됨, 고침 | 새 항목의 「종류」가 비어 블록이 틀린 값이 됐다. 꼭 골라야 하는 고르기는 첫 고르기로 채운다. |
| 새 블록 넣기 | 됨, 고침 | 마지막에 본 「꾸미기」 탭으로 열리고 캔버스가 그 블록으로 가지 않았다. 새 블록은 「내용」 탭으로 열고 다시 그린 뒤 그 자리로 옮긴다. |
| 동영상·사진 모음 | 됨 | 없음 |
| 내 블록 저장해 다른 페이지에 넣기 | 됨 | 없음 |
| 페이지 설정(설명) | 됨 | 없음 |
| 발행 | 됨 | 없음 |
| 사이트 기록에서 되돌리기 | 됨, 고침 | 두 곳을 고쳤는데 「고친 곳 16개」였다(블록 하나를 넣어 밀린 열네 블록까지 셈). 자리만 밀린 블록은 세지 않는다. 같은 묶음이 이제 2개로 보인다. 디자인 모음으로 화면을 통째로 바꾼 묶음은 바꾼 블록 수 그대로다. |
| 홈 화면에 추가 | 데스크톱만 확인 | 앱 정보·아이콘·서비스 워커·오프라인 안내는 데스크톱 브라우저에서 확인했다. 실제 휴대폰에서 홈 화면에 올리는 것은 아직 보지 못했다. |
