# 퀘이사존 화면 구성 브리프 (2026-11-05 관찰)

> 목적: Maru 커뮤니티 스킨·모듈 기획용 **기능과 화면 구성 목록**. clone-website 스킬의 1단계(작업 지도)·2단계(관찰)만 했고, 빌드·자산 내려받기는 하지 않았다.
> 원칙 7: 아래는 구성·흐름·기능의 기록이다. 색·장식·문구·코드는 옮기지 않는다. 회원 이름·글 본문은 적지 않았다.

## 0. 관찰 범위와 방법

- 도구: 내장 브라우저(숨은 창이라 스크린샷 없음) + DOM 측정(`getBoundingClientRect`, 계산된 스타일, 요소 목록). 데스크톱(창 너비 1101px)과 모바일 375×812 프리셋.
- 페이지 로드 18회. robots.txt 공통 규칙(`User-agent: *`)이 허용하는 주소만 열었다: `/`, `/bbs/<게시판>`, `/bbs/<게시판>/views/<번호>`.
- 참고: robots.txt 는 학습용 크롤러 `ClaudeBot` 을 전부 막는다. 이번 조사는 사용자가 지시한 브라우징이라 공통 규칙을 따랐다. 같은 조사를 자동화된 수집으로 돌리면 안 된다.
- 사고 1건: `/bbs/qb_jijang`(장터)을 열자 서버가 목록 권한이 없다는 알림 화면 `/messages` 로 보냈다(robots 비허용 경로). 알림 문구만 읽고 바로 떠났다.
- 로그인·글쓰기·추천·댓글·폼 제출·광고 클릭은 하지 않았다.

## 2. 사이트 공통 틀 (데스크톱)

- **고정 폭 1200px**(본문 안쪽 1170px, 좌우 여백 15px). 창이 1101px 이어도 페이지는 1200px 로 그려져 가로 스크롤이 생긴다 — 반응형이 아니라 데스크톱·모바일 템플릿을 따로 둔다(같은 주소, 기기 판별).
- **두 단**: 본문 단 약 776px + 오른쪽 곁가지 약 379px, 사이 16px. 갤러리형 게시판만 곁가지 없이 1170px 한 단.
- 글꼴: 한국어 산세리프 한 벌, 본문 14px. 숫자 축약 표기(천·만 단위, 예: 「4.3천」「5만」).
- 페이지 이동 일부를 Livewire(`wire:` 속성)로 부분 교체한다. 목록의 추천·댓글·조회 수에 `data-qc-*` 표지가 붙어 있어 **HTML 은 캐시하고 수치만 스크립트로 채우는 구조**로 보인다(Maru ADR-0042·0082 의 고민과 같은 방향).
- 화면 양옆 바깥에 고정 「스킨 광고」(좌우 각 300px), 오른쪽 아래 고정 단추 2개(맨 위로·맨 아래로).

## 4. 게시판 목록 — 공통 뼈대 (`v2` 목록)

위→아래:

1. **게시판 머리**: 게시판 이름 대신 운영자가 정한 **한 줄 안내 문구**(게시판 설명)가 제목 자리에 링크로.
2. **공지 줄**(게시판마다 1~3개): 「공지」 배지 · 제목 · 글쓴이 · 조회 · 날짜(YY.MM.DD). 일반 글보다 위에 고정.
3. 광고 자리(120px). 일부 게시판은 여기에 「배너 클릭 시 하루 10포인트」 안내 배너.
4. **분류 칩 탭**: 칩 폭 약 109px, 한 줄 7개씩 감싸 내려간다(뉴스·리뷰는 3줄까지). 자바스크립트로 분류를 바꾼다. 분류가 없는 게시판은 비어 있다.
5. **목록**: 한 쪽 30개(공식 리뷰 20, 이벤트 16).
6. **정렬 줄**: 왼쪽 정렬 선택(등록일 순·추천 순·조회수 순), 오른쪽 「글쓰기」 단추(비로그인이면 로그인으로). 즉 **글쓰기 단추는 목록 아래**.
7. **쪽 번호 카드**: 처음·이전 / 1~10 / 다음·마지막 + 검색 범위 선택(제목·제목+내용·댓글·닉네임) + 검색 칸.
8. 곁가지(379px): 로그인 상자 → **게시판 베스트**(이 게시판의 인기 글 순위 + 댓글 수) → 최신 파트너 핫딜(1/5 넘김) → 최신 공식 기사(1/5 넘김) → 배너.

## 6. 글 보기

4. (핫딜) **상품 정보 표**: 링크(제휴 링크 전환·수수료 고지 한 줄 포함) · 판매처 · 가격(원) · 배송비
5. 본문(위지윅 HTML)
6. 회원 서명 배너 자리(비어 있음)
7. **작성자 프로필 카드**(225px, 두 칸): 왼쪽 프로필 사진 · 레벨 아이콘 + 닉네임 · 쪽지 단추 · 차단 단추 · 레벨 이름 + 포인트 exp, 오른쪽 탭(게시물·댓글)으로 그 회원의 최근 글/댓글 목록. 아래 「회원 자기소개 펼치기」.
8. 광고(728×90)
9. **댓글**: 「댓글: N 개」 + 정렬(최신 순·과거 순). 댓글 한 개 = 프로필 사진 · 레벨 아이콘 + 닉네임 · 상대 시간(마우스 올리면 정확한 시각) · 본문. 답글은 한 단계 들여쓰기 + 앞에 `@닉네임` 링크 + 글쓴이 댓글엔 **「글쓴이」 표시**. 댓글 이미지 올리기 모달이 있다. 비로그인이면 댓글 칸 대신 로그인 안내 상자.
10. **글 아래 게시판 목록**: 목록 화면과 똑같은 머리·분류·필터·목록·쪽 번호가 다시 붙는다. 그래서 **이전글/다음글 링크는 없다**.

비로그인 화면에는 추천·비추천 단추가 그려지지 않는다. 다만 스크립트에 글·댓글 공통 추천/비추천 처리(1.5초 연타 막기, 「추천을 취소」 흐름), 신고 창, 스크랩 아이콘이 있어 **로그인하면 글과 댓글 모두 추천·비추천**이 있다고 본다(직접 확인 못 함).

### 6.2 갤러리 글 = 빠른 보기 모달

- 목록 위에 화면 전체 모달(주소 `?quick=<번호>`), 본문 폭 약 827px.
- 양옆 화살표: 「더 최신 글」「이전(더 과거) 글」로 모달 안에서 넘김. 닫기 단추.
- 오른쪽 떠 있는 알약 단추 묶음: **목록 · 추천(움직이는 아이콘) · 댓글(바로 이동) · 공유**.

## 7. 모바일 375px

- 같은 주소에 **별도 모바일 템플릿**. 가로 넘침 없음(scrollWidth 375).
- **머리글 고정 86px**: 왼쪽 메뉴(서랍) · 가운데 로고 · 오른쪽 아이콘 2개, 아래 **최근 방문 게시판 칩 줄**(가로로 넘김). 검색은 화면 전체 덮개 + 「최근 검색어 / 전체삭제」.
- 화면 아래 **고정 광고 77px**, 오른쪽 맨 위·맨 아래 단추.
- 첫 화면: 상단 광고 → 검색 칸 + 바로가기 6개(아이콘) → 콘텐츠(탭, 1/4) → 광고 → 데스크셋업 슬라이더 → 베스트(탭) → 뉴스 → 최신 핫딜 → 광고 → 질문/토론 최신글 → 광고 → 바닥글.
- 목록: 뒤로가기 + 게시판 이름 + 정렬 → 공지 → **게시판 베스트 3** → 분류 탭(가로 넘김, 칸 60px) → 두 줄 행 66px([1줄] 제목 + 댓글 수 / [2줄] 분류 · 레벨 + 닉네임 · 추천 · 조회 · 시간) → 쪽 번호 5개 → 검색.
- 글 보기: 뒤로가기 줄(게시판 이름) → 글 머리(분류 · 제목 · 댓글 수 / 글쓴이 · 추천 · 조회 · 시간) → 본문 → 글쓴이의 다른 활동 보기 링크 → 광고 → 댓글 → 최신 파트너 핫딜 → 최신 공식 기사 → 공식 기사 베스트 → 광고 → 게시판 목록.

## 9. 관찰하지 못한 것

- 로그인 화면 전부: 추천·비추천 단추 모양, 댓글 쓰기 에디터, 회원 막대 펼친 상태, 알림 목록, 쪽지.
- 레벨표·포인트 내역·출석체크·회원 순위(`/level/`, `/users/` 계열은 robots 비허용).
- 장터 목록(비로그인 권한 없음), 성능비교 `/perf`, 인기글·전체글 모음 `/best`·`/recent`(이번 범위의 주소 패턴 밖).
- 검색 결과·글쓰기 화면(robots 비허용), 핫딜 카드 보기(`?view=card`), 베스트 댓글 여부(본 글에선 없었음).
- 어두운 화면 실제 전환, 마우스 올림 상태의 모양(창이 숨어 스크린샷 불가).
