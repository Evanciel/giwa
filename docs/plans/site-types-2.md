# 사이트 종류(테마) 넓히기 계획 (ADR-0139)

> 관리 화면의 「테마」는 사이트 종류다(ADR-0137). 지금 12개(커뮤니티·블로그·회사·가게·기관·랜딩·포트폴리오·
> 매거진·강의·행사·채용·문서)에 한국에서 흔히 만드는 사이트 종류 10개를 더한다.
> 프리셋 파일(`crates/themes/builtin/presets/*.toml`)만 더하므로 CLI `maru init --preset`, MCP
> `create_site_from_preset`·`apply_theme`, 관리 화면 테마 카드가 함께 쓴다.

## 1. 벤치마킹 원칙

> 바로잡음(2026-11-08): §2 표는 처음에 실제 사이트를 열어 보지 않고 업종의 일반적인 배치로 썼다. 같은 날
> 대표 사이트를 브라우저로 직접 열어 본 결과와 그에 따라 고친 것은 §4 에 적는다(ADR-0140).

- 업종마다 사이트들이 공통으로 갖는 **구조**(메뉴 구성, 첫 화면 섹션 순서, 게시판 종류, 목록에 보이는 칸, 문의 흐름)만
  본다. 특정 사이트의 코드·이미지·문구·색은 옮기지 않는다(CLAUDE.md 원칙 7). 색과 모양은 우리 토큰으로 새로 정한다.
- 예시 글은 「무엇을 적을지」 안내하는 말로 쓴다. 지어낸 상호·인물·후기·수치를 사실처럼 쓰지 않는다
  (숫자 자리는 `00`, 상호 자리는 「가게 이름」).
- 업종 법규가 화면 구성에 닿는 곳은 구조에 반영한다. 법률 판단은 아니고, 운영자가 확인할 자리를 남기는 것이다.
  - 병원·의원: 의료법 제56조와 시행령 제23조는 환자 치료경험담 등 치료 효과를 오인하게 할 광고를 금지하고,
    로그인 같은 제한 없이 공개 게시하는 후기를 문제로 본다 → **후기 블록·후기 게시판을 두지 않는다.** 상담 게시판은 비밀글.
  - 쇼핑몰(통신판매): 상호·대표자·주소·전화·사업자등록번호·통신판매업 신고번호를 쉽게 볼 수 있게 표시하는 것이
    실무 기준 → 바닥글에 사업자 정보 자리를 둔다.
  - 부동산 중개: 공인중개사법 제18조의2와 국토교통부 고시가 표시·광고 명시사항을 정한다 → 바닥글에 중개사무소 정보
    자리, 매물 칸에 소재지·면적·가격·거래 종류·층·사용승인일·방향을 둔다. 정확한 항목은 운영자가 최신 고시로 확인한다.

기술 문서·위키 → 문서, 웹진·뉴스 → 매거진)은 더하지 않는다.

## 3. 만드는 것

- 프리셋 10개. 연산은 모두 「없으면 만든다」라 기존 사이트에 골라도 지우지 않는다(ADR-0137).
- 관리 화면 테마 카드: 「이런 사이트에」 한 줄과 견본 그림(SVG 속성만, 관리 CSP).
- CLI·MCP: 프리셋 목록은 파일에서 읽으므로 바뀔 것 없다. `AGENTS.md`·`llms.txt` 의 목록을 고친다.
- 테스트: `e2e_site_types` 의 전 종류 반복(첫 화면 200·h1 하나·섹션·모든 링크 살아 있음·두 번 실행해도 같음)에 10개를 더한다.
  폼 블록은 받은 내용이 DB 에 남는지, 게시판 칸 거르기가 되는지 몇 종류에서 본다.

## 4. 실제 사이트 관찰과 고친 것 (2026-11-08, ADR-0140)

브라우저로 직접 열어 메뉴, 첫 화면 섹션 순서, 곁가지, 바닥글을 적었다. 로그인하지 않은 공개 첫 화면과
상세 한 쪽만 봤다. 문구·색·그림·코드는 옮기지 않았고, 아래 「옮긴 구조」만 우리 블록으로 새로 만들었다.

| 종류 | 열어 본 곳 | 본 구조 | 옮긴 구조 |
|---|---|---|---|
| 커뮤니티 | 퀘이사존 | 큰 묶음 메뉴(정보·질문·커뮤니티·장터), 검색과 바로가기 단추, 맨 위 콘텐츠 최신·인기 탭, 게시판 판 두 칸씩, 곁가지 로그인 상자·실시간 인기·최신 장터 글 | 맨 위 「전체 글」 최신·인기 탭, 정보·팁 게시판, 장터 게시판(팝니다·삽니다·나눔, 거래 중·예약 중·거래 완료로 거르기), 곁가지 장터 새 글, 이벤트를 메뉴에 |
| 쇼핑몰 | 무신사, 29CM, 디스이즈네버댓 | 위 혜택 띠, 분류 둥근 칸 줄, 기획전·룩북 같은 편집 글, 상품 바둑판, 매장 안내, 바닥글 사업자 정보·약관 | 위 혜택 띠(`notice_bar`), 분류 바로가기 칸(할인 분류 더함), 룩북·이야기 게시판, 매장 안내 쪽(영업시간·오시는 길) |
| 중개 플랫폼 | 숨고, 크몽 | 지역·분야 검색 큰 칸, 분야 아이콘 줄, 추천 업체 카드, 이용 방법 단계, 지역별 찾기, 「전문가로 활동하시나요」 띠, 바닥글에 중개자 고지 | 분야·지역 바로가기 칸, 바닥글에 「거래의 당사자가 아닙니다」와 사업자 정보 자리 |
| 병원 | 우리들병원 (한 체인은 지점 고르기 화면뿐이라 뺐다) | 병원 소개·진료 안내·치료 정보·지점 메뉴, 숫자 띠, 「어디가 아프신가요」 부위 고르기, 아래 고정 전화·예약·오시는 길 단추 | 큰 그림 아래 빠른 메뉴 칸, 「어디가 불편하세요」 증상·부위 칸. 숫자 띠와 후기는 넣지 않는다(의료법 제56조) |
| 학원 | 크레버스(청담어학원 등) | 윗줄 입학시험 예약·수강료 납입, 입학 절차 메뉴, 개강 소식·공지·뉴스 세 줄, 입학시험 예약 팝업, 합격 실적, 학원 찾기 | 입학 상담·시간표·수강료 바로가기 칸, 공지·수업 소식 탭, 상담 폼에 「레벨 테스트 예약」과 원하는 날짜. 합격 실적 숫자는 넣지 않는다 |

여러 곳에 공통으로 있던 「분류·바로가기 둥근 칸 줄」은 `features` 의 새 모양 `tiles` 로 만들었다. 아이콘 그림은
남의 것을 쓰지 않고 글자 칸으로 둔다. 병원의 아래 고정 단추 줄은 지금 `sticky` 영역이 광고 자리(닫기 단추가
「광고 닫기」)라 넣지 않았다.

법규 확인:
- 통신판매중개자는 자신이 통신판매의 당사자가 아니라는 사실을 사이버몰 초기 화면에 알린다(전자상거래법 제20조 제1항,
  시행규칙 제11조의2). 2025년 공정위가 초기 화면에 알리지 않은 중고 거래 플랫폼에 이행명령을 내렸다.
- 학원은 교습비를 거짓으로 표시·게시하지 못하고 게시한 금액보다 더 받지 못한다(학원법 제15조). 홈페이지에 등록번호를
  표시할 의무는 이번에 확인하지 못해 자리를 만들지 않았다.
